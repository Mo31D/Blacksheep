# The Black Sheep Shop — Ambleside

Static website for The Black Sheep Shop in Ambleside, Lake District.

This repository contains the current site structure, product catalogue data, category pages, visit information, and the Black Sheep visual identity.

## Images
Current numbered product/category images are temporary placeholders. Replace files in `/images` using the same filenames as new in-store photography becomes available; no page-code changes are required.

## Main collections
Peter Rabbit, Highland Cows, Fridge Magnets, Mugs & Tableware, Souvenirs, Soft Toys, Cards & Stationery, Seasonal Gifts, Keyrings & Badges, Maps/Books/Jigsaws, local treats, Lakeland Fragrances, Home Gifts & Art, Toys & Games, Romney's, Hawkshead Relish, and Ice Cream.
